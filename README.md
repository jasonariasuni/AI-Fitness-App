# AI Fitness App

## Project Overview

AI Fitness App is a web-based fitness and nutrition application created for CMSC 355. The goal of this project is to help users manage their fitness goals by providing access to workout tools, calorie tracking, exercise information, and an AI assistant feature.

## Features

- Home page with navigation to different fitness tools
- Exercise section for workout-related information
- Calorie section for nutrition and tracking support
- AI assistant section for fitness-related help
- Clean and simple user interface built with HTML, CSS, and JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## How to Run the Project

To run the project locally, download the repository and open the `index.html` file in a web browser.

You can also use VS Code Live Server:

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select `Open with Live Server`.

## GitHub Pages

This project can be published using GitHub Pages.

After uploading the files to GitHub:

1. Go to the repository settings.
2. Click `Pages`.
3. Set the source to `Deploy from a branch`.
4. Select the `main` branch and `/root` folder.
5. Save the changes.
6. Open the generated GitHub Pages link.
